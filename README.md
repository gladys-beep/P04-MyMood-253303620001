## Cara Menjalankan Proyek
1. Clone atau download repositori ini ke komputer.
2. Buka terminal di dalam folder proyek, lalu instal dependensi dengan perintah:
   ```bash
   npm install
3. Jalankan server lokal
   ```bash
   npx expo start  
5. Scan QR code yang muncul menggunakan aplikasi Expo Go di HP fisikmu.
